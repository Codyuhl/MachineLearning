# Machine Learning Portfolio Projects

This repository contains machine learning projects covering classical classifiers, multilayer perceptrons, convolutional neural networks, preprocessing workflows, model evaluation, and presentation-ready reporting.

These projects were originally completed as part of university machine learning coursework and have been organized as portfolio examples.

## Project Overview

The repository demonstrates applied machine learning across multiple problem types:

1. Classical machine learning classifiers
2. Neural network classification
3. Convolutional neural network image classification

The projects emphasize the full modeling workflow, including data preparation, training, evaluation, visualizations, and interpretation of results.

## Projects

### 1. Classical ML Classifiers

Implementation and evaluation of traditional machine learning classification methods.

**Focus Areas:**

- Data preprocessing
- Train/test evaluation
- Classifier comparison
- Accuracy and performance metrics
- Interpretation of model results

### 2. Adult Income Prediction with MLP

Neural network project focused on predicting income categories using structured demographic and employment-related features.

**Focus Areas:**

- Multilayer perceptron modeling
- Feature preprocessing
- Classification evaluation
- Model performance comparison
- Practical interpretation of predictive results

### 3. Razorback Logo CNN Image Classification

Image classification project using a convolutional neural network to identify Razorback logo images.

**Focus Areas:**

- Image preprocessing
- CNN training
- Binary classification
- AUC and evaluation metrics
- Visual model reporting
